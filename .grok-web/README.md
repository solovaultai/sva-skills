# grok.com skills

On grok.com, create a skill and upload or paste that file. One skill per mode.

The create path is [Grok Skills](https://x.ai/news/grok-skills): describe a skill, upload a file, or write it in the UI.

This directory is not `~/.grok/skills`. That path is the Grok coding agent.

| Mode | Upload or paste | What it does |
|------|-----------------|--------------|
| ify | `skills/ify/SKILL.md` | Catalog the pack and recommend which mode to open. |
| askify | `skills/askify/SKILL.md` | Answer the question. No edits and no plan. |
| promptify | `skills/promptify/SKILL.md` | Rewrite the prompt. Do not execute it. |
| plannify | `skills/plannify/SKILL.md` | Write a plan and end with a phase list. |
| debugify | `skills/debugify/SKILL.md` | Debug kickoff: hypotheses and what to check. No instrumentation and no fix. |
| addify | `skills/addify/SKILL.md` | Append text to the previous coaching request and redo that mode. |
